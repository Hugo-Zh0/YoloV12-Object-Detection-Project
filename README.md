## 📌 Overview
A **collaborative group project** by Swinburne University students in partnership with **CSIRO**.  
This repository contains the setup, configuration, and workflow for training and running **YOLOv12** object detection models.

**👨‍💻 Team Members:** Harron, Feng, Bunmi, Huss, Hugo.

## 📦 Prerequisites

Before you begin, make sure you have downloaded the Colab File (can either save it locally or google drive)
Next you want to open up colab.research.google.com (sign-in or create account to use this website)
You then next want to upload the colab file into the website to use (now you can follow the steps on the colab file to continue)
